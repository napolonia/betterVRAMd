2. ARCHITECTURE DECISIONS
VRAMdManager owns ModelRegistry and RAMCacheManager.
VRAMdManager owns LifecycleController and InferenceScheduler.
LifecycleController receives registry and cache references through dependency injection.
Model registration never automatically loads models.
Application startup never automatically warms model pages.
No GPU allocation while idle.
RAM caching uses mmap.
No mlock by default.
Inference execution belongs to the worker subsystem.

See PROJECT_CONTEXT.txt for complete architecture.
