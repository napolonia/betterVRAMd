============================================================
2. INFERENCE ARCHITECTURE
============================================================

Primary backend: llama-server.
Future optional backend: llama-cli.

base.py:
Defines the common backend interface and result types.

llama_cpp.py:
Builds llama-server commands.
Validates executable and model paths.
Communicates with the running server through HTTP.
Provides readiness checks and inference requests.

worker/process.py:
Creates and owns the llama-server subprocess.
Monitors process startup and termination.
Handles graceful and forced shutdown.
Tracks the selected server port.

LifecycleController:
Coordinates model loading and unloading.

InferenceScheduler:
Coordinates inference request scheduling.

Only one inference worker/server may be active at a time.

============================================================
3. CONFIGURATION
============================================================

Configuration is defined through:

vramd/core/config.py
config/default.toml

TOML_MAPPING connects configuration sections to VRAMdConfig.

Environment variables use the VRAMD_ prefix and override TOML.

llama-server settings include:

- server_host
- server_port
- server_dynamic_port
- server_startup_timeout_seconds
- server_request_timeout_seconds
- server_health_check_interval_seconds
- server_max_parallel_requests
- server_api_key_file

Worker settings include:

- use_separate_process
- shutdown_timeout_seconds
- force_termination
- restart_on_crash
