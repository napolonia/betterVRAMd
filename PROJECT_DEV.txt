2. ARCHITECTURE DECISIONS
Component ownership
VRAMdManager owns ModelRegistry.
VRAMdManager owns RAMCacheManager.
LifecycleController receives references to both through dependency injection.
InferenceScheduler manages inference request ordering.
Worker subsystem executes inference requests.
Model lifecycle

Registration must never automatically load models.

Application startup must never automatically:

Load GGUF files into RAM.
Warm model pages.
Allocate GPU resources.

Model states currently include:

Registered
Cached

Future inference states and GPU lifecycle states must be handled separately.

Memory management
Use mmap for model files.
Avoid unnecessary memory copies.
No mlock by default.
Page warming must be optional.
GPU resources must be released after inference.
Verify actual VRAM reclamation where supported.
